# bolcanar-web

Sitio de Mieles Bolcanar. GitHub Pages publica `main` en bolcanar.com. Esta rama no está fusionada.

Archivos para leer el sitio:

- `index.html` — la página
- `css/styles.css` — estilos
- `js/main.js` — menú y respaldo de las transiciones
- `js/motion.js` — Motion, solo en botones y transiciones
- `js/shopify.js` — compra preparada y oculta, sin tienda ni credenciales
- `img/` — las fotografías que ya tenía la página
- `CNAME` — bolcanar.com
- `.nojekyll`

El video de héroe y las fotos 360° todavía no existen. Los huecos están marcados en `index.html` y no se ven en la página.
